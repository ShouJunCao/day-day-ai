10.1 AI Agent 架构概述与 ReAct 模式

  • 能够设计 Agent 的工具注册和执行系统

一、AI Agent 概述

AI Agent 是一种能够感知环境、进行推理并采取行动以实现目标的智能系统。与传统的 AI 模型不同，AI Agent 不仅能生成文本或图像，还能主动使用工具、获取信息、执行操作，并在复杂环境中进行多步推理和决策。这种能力的飞跃使得 AI Agent 成为当前人工智能领域最具前景的方向之一。

AI Agent 的核心特征包括：自主性（能够独立完成任务而无需人工干预）、反应性（能够感知环境变化并做出响应）、主动性（能够主动采取行动以实现目标）、社会性（能够与其他 Agent 或人类协作）。这些特征共同构成了 Agent 区别于传统 AI 模型的本质属性。

在实际应用中，AI Agent 已经被广泛应用于代码生成与调试、数据分析与报告、客户服务与对话、自动化测试与部署、知识管理与检索等多个领域。随着大语言模型能力的不断提升，AI Agent 的应用场景正在快速扩展，越来越多的企业和开发者开始探索 Agent 技术在各自业务中的落地方案。

从技术演进的角度来看，AI Agent 的发展经历了从规则驱动到模型驱动的范式转变。早期的 Agent 系统主要依赖手工编写的规则和策略，而现代的 Agent 系统则以大语言模型为核心，通过提示工程和工具调用来实现复杂任务的自动化。这种转变使得 Agent 系统的开发变得更加高效和灵活。

1.1 Agent 架构组成

一个典型的 AI Agent 由四个核心组件构成：大脑（LLM）、记忆（Memory）、工具（Tools）和行动（Action）。这四个组件协同工作，使 Agent 能够完成复杂的任务。

二、ReAct 模式

ReAct（Reasoning + Acting）是一种将推理和行动结合的 Agent 架构模式。它通过在 LLM 的提示词中交替注入"思考"和"行动"步骤，使 Agent 能够在每一步都进行推理，然后决定使用什么工具，最后根据工具返回的观察结果进行下一步推理。

ReAct 模式的核心优势在于：它将推理过程显式化，使 Agent 的决策过程更加透明和可解释；通过交替执行推理和行动，Agent 能够更好地处理需要多步推理的复杂任务；工具的观察结果直接融入推理过程，使 Agent 能够根据实时信息调整策略。

ReAct 模式的基本循环包含三个阶段：思考（Thought，分析问题并决定下一步行动）、行动（Action，调用工具获取信息或执行操作）、观察（Observation，获取工具返回的结果并用于下一步推理）。这个循环持续执行，直到 Agent 得出最终答案或达到最大迭代次数。

三、工具注册与执行系统

工具是 Agent 与外部世界交互的桥梁。一个完善的工具系统应该包含：工具定义（描述工具的名称、功能和参数）、工具注册（将工具添加到 Agent 的工具库中）、工具执行（根据名称和参数调用工具）、工具描述生成（将工具信息格式化为 LLM 可理解的格式）。

在设计工具时，建议遵循以下原则：每个工具只做一件事，保持功能的单一性和明确性；工具名称应该使用动词加名词的格式，使 Agent 能够直观理解工具的功能；工具描述应该简洁明了地说明工具的用途和参数要求；工具输入参数应该使用 JSON Schema 格式定义，便于 Agent 生成正确的参数。

3.1 工具定义与注册

Python（工具注册系统）
from dataclasses import dataclass
from typing import Callable, Dict

@dataclass
class AgentTool:
    """Agent 工具定义"""
    name: str
    description: str
    func: Callable
    input_schema: Dict[str, str]

class ToolRegistry:
    """工具注册表"""
    def __init__(self):
        self.tools = {}

    def register(self, tool):
        self.tools[tool.name] = tool

    def execute(self, name, arguments):
        if name not in self.tools:
            return {"error": f"Unknown tool: {name}"}
        return self.tools[name].func(**arguments)

四、ReAct Agent 核心实现

ReAct Agent 的核心是一个循环：每次迭代中，Agent 首先根据当前信息和任务生成思考，然后决定是否需要调用工具以及调用哪个工具，接着执行工具并获取观察结果，最后将观察结果融入上下文进行下一轮思考。

Agent 的提示词设计至关重要。提示词需要清晰地描述可用工具、回答格式要求和任务描述。提示词的结构应该包含系统指令（定义 Agent 的角色和行为）、工具描述（列出所有可用工具及其参数）、格式要求（规定输出格式）、任务描述（提供需要解决的问题）。

4.1 Agent 主循环

Python（ReAct Agent 核心）
class ReActAgent:
    """ReAct Agent 实现"""
    
    SYSTEM_PROMPT = """你是一个 AI Agent，使用 ReAct 模式解决问题。
你可以使用以下工具：
{tools}

回答格式必须严格遵守：
Thought: <思考过程>
Action: <工具名称>
Action Input: <JSON 格式参数>
Observation: <工具返回结果>
... (循环)
Thought: <思考过程>
Final Answer: <最终答案>"""

    def __init__(self, registry, max_iterations=5):
        self.registry = registry
        self.max_iterations = max_iterations

    def run(self, query):
        """执行 ReAct 循环"""
        prompt = self.SYSTEM_PROMPT.format(
            tools=json.dumps(self.registry.get_tools_description())
        ) + f"\n\nQuestion: {query}\n"
        
        for i in range(self.max_iterations):
            # 调用 LLM 生成响应
            response = client.chat.completions.create(
                model="qwen3.7-max",
                messages=[{"role": "user", "content": prompt}]
            )
            
            # 解析响应
            parsed = self._parse_response(response.choices[0].message.content)
            
            # 检查是否完成
            if parsed["final_answer"]:
                return parsed["final_answer"]
            
            # 执行工具
            observation = self.registry.execute(
                parsed["action"],
                json.loads(parsed["action_input"])
            )
            
            # 更新 Prompt
            prompt += f"Observation: {observation}\n"

五、Agent 响应解析

Agent 的响应解析是将 LLM 生成的结构化文本转换为可执行命令的关键步骤。ReAct Agent 的响应通常包含三个部分：思考（Thought）描述 Agent 的分析过程和决策理由，行动（Action）指定要调用的工具名称，行动输入（Action Input）提供工具所需的参数。

在实际实现中，响应解析需要使用正则表达式来提取各个部分。为了确保解析的可靠性，应该在提示词中明确规定输出格式，并在解析失败时提供重试机制。同时，应该记录完整的 Agent 执行轨迹，便于调试和优化。

5.1 响应解析实现

Python（响应解析）
import re

class ResponseParser:
    """ReAct 响应解析器"""
    
    def parse(self, response):
        thought = re.search(r"Thought:\s*(.*)", response)
        action = re.search(r"Action:\s*(.*)", response)
        input_m = re.search(r"Action Input:\s*(.*)", response)
        final = re.search(r"Final Answer:\s*(.*)", response, re.DOTALL)
        
        return {
            "thought": thought.group(1) if thought else "",
            "action": action.group(1).strip() if action else "",
            "input": input_m.group(1).strip() if input_m else "{}",
            "final": final.group(1).strip() if final else ""
        }

六、Agent 记忆系统

记忆系统是 Agent 保持上下文连贯性的关键组件。ReAct Agent 的记忆主要包括两种：短期记忆（对话历史和当前任务的执行轨迹）和长期记忆（跨会话的知识存储）。在 ReAct 模式中，执行轨迹本身就是短期记忆的重要组成部分，它记录了 Agent 的每一步思考、行动和观察结果。

在实际应用中，建议将 Agent 的执行轨迹持久化存储，以便后续分析和优化。轨迹数据可以用于评估 Agent 的决策质量、发现工具调用的瓶颈、优化提示词设计等。同时，轨迹数据也可以用于训练更高效的 Agent 模型。

6.1 轨迹记录

class AgentTrace:
    """Agent 执行轨迹记录"""
    
    def __init__(self):
        self.trace = []

    def add(self, step_type, content):
        self.trace.append({
            "step": step_type,
            "content": content,
            "timestamp": time.strftime("%H:%M:%S")
        })

    def get_summary(self):
        return [f"{t['step']}: {t['content'][:50]}" for t in self.trace]

七、Agent 评估与优化

评估 Agent 的性能是持续改进的重要环节。常用的评估指标包括：任务完成率（Agent 能否正确完成任务）、效率（完成任务所需的迭代次数）、准确性（最终答案的正确性）、工具使用合理性（是否选择了合适的工具）。

优化 Agent 的方法包括：改进提示词设计（使格式要求更加明确）、调整最大迭代次数（平衡准确性和效率）、优化提示词模板（提供更清晰的示例）、增强错误处理（当工具调用失败时提供恢复策略）。

实战建议

在开发 ReAct Agent 时，建议先从一个简单的场景开始（如数学计算或天气查询），逐步增加工具的复杂度和数量。在提示词设计中，提供清晰的格式示例可以显著提高 LLM 的格式遵循度。同时，建议为每个工具编写单元测试，确保工具的稳定性和可靠性。

八、小结

ReAct 模式是 AI Agent 开发中最经典和实用的架构之一。它通过将推理和行动有机结合，使 Agent 能够在复杂环境中进行多步推理和决策。理解 ReAct 模式的核心原理和实现方法，是开发高效 AI Agent 的基础。在实际项目中，可以根据任务需求选择合适的 Agent 架构，并不断优化提示词设计和工具系统。
