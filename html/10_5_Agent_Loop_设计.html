10.5 Agent Loop 设计（ReAct、Plan-and-Execute、Reflexion）

模块十：AI Agent 开发 预计学习：50 分钟

  • 掌握 ReAct、Plan-and-Execute、Reflexion 的实现方法
  • 学会根据任务特征选择合适的循环模式
  • 能够设计组合式循环以应对复杂场景

一、Agent Loop 概述

Agent Loop（代理循环）是 Agent 运行的核心控制逻辑。它决定了 Agent 如何思考、如何行动、如何观察结果以及如何迭代。不同的循环模式适用于不同类型的任务，理解它们的差异是构建高效 Agent 的关键。

在 Agent 开发中，选择合适的循环模式可以显著提高任务完成率和执行效率。ReAct 适合需要频繁与环境交互的场景，Plan-and-Execute 适合步骤明确的长程任务，而 Reflexion 则适合对输出质量要求极高的场景。

1.1 三种循环模式对比

二、ReAct Loop

ReAct（Reasoning + Acting）循环是最经典的 Agent 执行模式。它的核心思想是让 Agent 在每一步都进行思考，然后决定行动，最后观察行动的结果。这种交替进行的模式使 Agent 能够处理需要多步推理和工具调用的复杂任务。

ReAct Loop 的实现相对简单，主要由一个提示词模板和一个解析器组成。提示词模板定义了 Agent 的输出格式，解析器负责提取 Agent 的决策并执行相应的工具。ReAct 的优势在于灵活性高，Agent 可以根据当前的观察结果动态调整下一步的行动，而不需要预先制定完整的计划。

三、Plan-and-Execute Loop

Plan-and-Execute（规划 - 执行）循环采用两阶段策略：首先由 LLM 制定完整的执行计划，然后按照计划逐步执行。这种模式将规划与执行分离，使得执行过程更加可控，便于监控和干预。

Plan-and-Execute 的核心优势在于其可预测性。由于计划在执行前就已经确定，开发者可以预先知道 Agent 将采取哪些步骤，这对于需要审计和合规的场景非常重要。此外，这种模式也便于并行执行不相关的步骤，从而提高整体效率。

3.1 Plan-and-Execute 实现

Python（Plan-and-Execute Loop）
class PlanAndExecuteLoop:
    PLANNER_PROMPT = """请将目标分解为有序的步骤列表。
目标：{goal}
输出 JSON 列表：[{{"step": "步骤 1"}}, ...]"""

    def run(self, goal):
        # 1. Planning Phase
        plan = self._generate_plan(goal)
        
        # 2. Execution Phase
        results = []
        for step in plan:
            result = self._execute_step(step, results)
            results.append(result)
            if "COMPLETE" in result.upper():
                break
        
        return {"plan": plan, "execution": results}

四、Reflexion Loop

Reflexion（反思）循环引入了自我评估和纠错机制。在这种模式下，Agent 不仅执行任务，还会对执行结果进行反思，识别不足之处，并根据反思结果修正后续行动。这种"执行 - 反思 - 修正"的循环使 Agent 能够不断提高输出质量。

Reflexion 的核心在于反思提示词的设计。一个好的反思提示词应该能够引导 LLM 从多个维度评估输出质量，包括准确性、完整性、一致性等。通过多轮反思，Agent 可以逐步消除错误，最终生成高质量的输出。

4.1 Reflexion 实现

Python（Reflexion Loop）
class ReflexionLoop:
    REFLECTION_PROMPT = """请评估以下执行结果。
目标：{goal}
当前结果：{current_result}
输出 JSON：{{"is_perfect": true/false, "feedback": "建议"}}"""

    def run(self, goal, executor, max_iterations=3):
        for i in range(max_iterations):
            # 1. Execute
            result = executor(goal)
            
            # 2. Reflect
            feedback = self._reflect(goal, result)
            
            if feedback.get("is_perfect"):
                return result
            
            # 3. Modify (修正执行逻辑或输入)
            executor = self._modify_executor(executor, feedback)
        
        return result

六、组合式循环设计

在实际项目中，单一循环模式往往无法满足复杂需求。通过组合不同的循环模式，可以构建更加强大的 Agent 系统。例如，可以使用 Plan-and-Execute 进行高层规划，然后在每个步骤中使用 ReAct 进行具体执行，最后使用 Reflexion 对关键输出进行质量检查。

组合式循环设计的关键在于明确每个子循环的职责边界。高层循环负责宏观规划和进度控制，底层循环负责具体任务的执行和优化。通过合理的职责划分，可以避免循环之间的冲突，确保整体执行的顺畅。

6.1 组合示例

Python（组合循环示例）
# 高层使用 Plan-and-Execute
plan = planner.run("生成数据分析报告")

# 每个步骤使用 ReAct 执行
for step in plan["steps"]:
    result = react_loop.run(step)
    
    # 关键步骤使用 Reflexion 检查
    if step.is_critical:
        reflection = reflexion_loop.run(step, result)
        if not reflection["is_perfect"]:
            # 修正并重新执行
            result = react_loop.run(step, reflection["feedback"])
💡 实战建议

在设计 Agent Loop 时，建议从最简单的 ReAct 模式开始，验证核心逻辑的正确性。当任务复杂度增加时，再逐步引入 Plan-and-Execute 或 Reflexion 模式。组合式循环虽然强大，但也增加了系统的复杂性，应谨慎使用，确保每个子循环都有明确的责任和边界。

七、小结

Agent Loop 是 Agent 系统的核心控制逻辑。ReAct 适合灵活交互，Plan-and-Execute 适合可控执行，Reflexion 适合高质量输出。通过合理选择和组合这些模式，可以构建出能够应对各种复杂任务的强大 Agent 系统。在实际开发中，应根据任务特征和性能要求，选择最适合的循环模式。
