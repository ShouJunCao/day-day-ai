一、Agent 可观测性概述

Agent 可观测性（Observability）是指通过收集、分析和可视化 Agent 执行过程中的各种数据，来理解系统内部状态和行为的能力。与传统软件的可观测性不同，Agent 的可观测性面临更多挑战：执行过程非确定性（相同的输入可能产生不同的输出）、多步骤交互（需要追踪完整的调用链）、外部依赖（工具调用和 LLM 响应）。

可观测性的核心价值在于：帮助开发者理解 Agent 的决策过程（为什么做出某个选择）、快速定位问题（哪一步出了错）、持续优化性能（哪些环节需要改进）。没有可观测性的 Agent 就像一个"黑盒"，开发者无法了解内部发生了什么，也就无法有效地调试和优化。

完整的 Agent 可观测性体系包含三个层次：追踪（Tracing，记录执行的详细路径）、监控（Monitoring，实时跟踪关键指标）、评估（Evaluation，衡量输出质量）。这三个层次相互补充，共同构成了 Agent 可观测性的完整视图。在实际项目中，这三个层次通常由不同的工具或平台来提供支持，开发者需要根据项目需求选择合适的组合。

1.1 可观测性三层架构

二、LangSmith

LangSmith 是 LangChain 官方推出的 Agent 追踪和调试平台。它提供了完整的调用链追踪功能，能够记录 Agent 执行过程中的每一个步骤，包括 LLM 调用、工具执行、中间状态等。LangSmith 的核心优势在于与 LangChain 生态的深度集成，开发者几乎不需要额外配置即可开始使用。

LangSmith 的主要功能包括：调用链可视化（以树形结构展示 Agent 的执行路径）、延迟分析（识别执行中的瓶颈步骤）、Token 消耗跟踪（分析每次 LLM 调用的 token 使用情况）、数据集管理（保存和管理测试用例）、版本对比（比较不同版本 Agent 的性能差异）。通过这些功能，开发者可以快速了解 Agent 的执行效率和资源消耗情况，从而有针对性地优化 Agent 的性能和成本。

使用 LangSmith 时，开发者只需在代码中添加少量的追踪注解，即可自动收集所有执行数据。这些数据会自动上传到 LangSmith 平台，开发者可以通过 Web 界面查看详细的执行报告和性能分析。对于使用 LangChain 构建的 Agent 应用，LangSmith 是最便捷的可观测性解决方案，能够帮助开发者快速定位问题并持续改进 Agent 的质量。

三、LangFuse

LangFuse 是一个开源的 LLM 工程平台，专注于 Agent 和 LLM 应用的监控和评估。与 LangSmith 不同，LangFuse 支持自托管部署，适合对数据隐私有严格要求的企业。LangFuse 提供了丰富的 API 和 SDK，支持多种编程语言和框架，使得开发者可以根据自己的需求灵活地集成可观测性功能。LangFuse 的核心优势在于其开源性质和自托管能力，所有数据都可以保存在自有服务器上，避免将敏感信息传输到第三方平台。

LangFuse 的核心功能包括：追踪管理（记录和管理所有 LLM 调用）、评分系统（对 Agent 输出进行人工或自动评分）、提示词版本管理（跟踪提示词的演变历史）、成本分析（详细分析 token 消耗和费用）、A/B 测试（比较不同提示词或模型的效果）。这些功能的组合使得 LangFuse 成为一个全面的 LLM 工程平台，不仅能够监控 Agent 的运行状态，还能够持续优化其性能和成本。

在实际使用中，LangFuse 特别适合需要数据隐私控制的场景。通过自托管部署，企业可以确保所有的追踪数据、评分结果和分析报告都保存在内部服务器上，满足合规和安全要求。同时，LangFuse 的开源性质意味着开发者可以深入了解其内部实现，并根据特定需求进行定制开发。

3.1 LangFuse 集成示例

Python（LangFuse 集成）
from langfuse import Langfuse

# 初始化
langfuse = Langfuse(
    public_key="pk-lf-xxx",
    secret_key="sk-lf-xxx",
    host="https://cloud.langfuse.com"
)

# 创建追踪
trace = langfuse.trace(name="agent-execution")

# 记录生成
generation = trace.generation(
    name="llm-call",
    model="qwen3.7-max",
    input="分析销售数据",
    output="销售数据分析报告..."
)

# 记录评分
trace.score(name="accuracy", value=0.95)

四、Phoenix

Phoenix 是 Arize AI 推出的开源 LLM 可观测性平台，专注于 Agent 应用的评估和调试。Phoenix 提供了独特的"时间旅行"功能，允许开发者回放 Agent 的执行过程，逐步检查每个决策点。这种能力对于调试复杂的 Agent 行为非常有用。

Phoenix 的核心特色在于其强大的评估能力。它支持多种评估方法：基于规则的评估（使用预定义的规则检查输出）、基于模型的评估（使用 LLM 作为评判者）、人工标注（支持团队协作标注）。Phoenix 还提供了丰富的可视化图表，帮助开发者直观地理解 Agent 的行为模式。

4.1 Phoenix 集成示例

Python（Phoenix 集成）
import phoenix as px
import pandas as pd
from phoenix.evals import run_evals

# 启动 Phoenix
session = px.launch_app()

# 准备评估数据
data = pd.DataFrame({
    "query": ["问题 1", "问题 2"],
    "response": ["回答 1", "回答 2"],
    "reference": ["参考答案 1", "参考答案 2"]
})

# 运行评估
evals = run_evals(
    dataframe=data,
    evaluators=["accuracy", "relevance"],
    display_progress=True
)

六、自建可观测性系统

虽然现成的可观测性平台功能强大，但在某些场景下，开发者可能需要自建可观测性系统。自建系统的优势在于：完全可控（根据业务需求定制功能）、数据自主（所有数据保留在自有服务器上）、成本可控（避免平台订阅费用）。但自建系统也需要投入更多的开发和维护成本。

自建可观测性系统的核心组件包括：追踪器（记录执行路径和时间线）、指标收集器（收集性能指标）、评估器（评估输出质量）、数据存储（持久化追踪和指标数据）、可视化界面（展示分析结果）。通过组合这些组件，可以构建出满足特定需求的可观测性系统。

6.1 自建追踪器实现

Python（自建追踪器）
import uuid
import time
from dataclasses import dataclass

@dataclass
class TraceSpan:
    span_id: str
    name: str
    start_time: float
    end_time: float = None
    status: str = "pending"
    metadata: dict = None

class AgentTracer:
    """自建 Agent 追踪器"""
    
    def __init__(self):
        self.spans = []
    
    def start_span(self, name):
        span = TraceSpan(
            span_id=str(uuid.uuid4()),
            name=name,
            start_time=time.time()
        )
        self.spans.append(span)
        return span
    
    def end_span(self, span, status="success"):
        span.end_time = time.time()
        span.status = status

七、可观测性最佳实践

在实施 Agent 可观测性时，建议遵循以下最佳实践：首先在开发阶段就集成追踪功能，而不是等到出现问题后再添加；其次选择合适的采样策略，在数据量和成本之间取得平衡；然后建立清晰的指标定义和告警规则，确保关键问题能够及时被发现；最后定期回顾和分析可观测性数据，持续优化 Agent 的性能和可靠性。

可观测性数据的价值不仅在于问题排查，更在于持续改进。通过分析 Agent 的执行数据，可以发现性能瓶颈、优化提示词设计、改进工具调用策略。建议将可观测性数据的分析纳入日常开发流程，使其成为 Agent 迭代优化的重要依据。

💡 实战建议

对于新项目，建议先使用 LangSmith（如果使用 LangChain）或 LangFuse（如果需要自托管）快速建立基础的可观测性能力。随着项目复杂度增加，再逐步引入 Phoenix 进行深度评估。不要等到出现问题才想起添加可观测性——从项目第一天起就集成追踪和监控，是确保 Agent 系统长期稳定运行的关键。

八、小结

Agent 可观测性是确保 Agent 系统可靠运行的关键基础设施。LangSmith 提供了开箱即用的追踪调试能力，LangFuse 提供了灵活的监控和评估平台，Phoenix 则专注于深度的评估分析。通过合理选择和组合这些工具，可以构建出全面的可观测性体系，帮助开发者理解、监控和持续优化 Agent 的行为。
