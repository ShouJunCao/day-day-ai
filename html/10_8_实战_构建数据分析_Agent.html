一、项目概述

数据分析 Agent 是本模块的综合实战项目。它将前面学习的所有核心技术（ReAct 循环、任务规划、工具编排、异常处理、熔断器、可观测性）整合到一个完整的应用中，实现一个能够自动执行数据分析全流程的智能 Agent。这个项目不仅是对前面知识的综合运用，更是对实际开发能力的全面检验。

这个 Agent 的工作流程包括：理解分析需求 → 规划分析步骤 → 查询数据 → 执行统计分析 → 生成分组报告 → 输出最终分析结论。每个步骤都由 Agent 自动决策和执行，开发者只需要提供分析任务和可用工具的定义。通过这种方式，Agent 能够灵活应对各种数据分析需求，而不需要为每种场景编写专门的代码。

通过这个项目，你将看到一个真实的 Agent 系统是如何将多个技术组件有机组合在一起的。这种综合应用能力是成为高级 Agent 开发者的关键。在实际项目中，数据分析 Agent 可以对接真实的数据源，如数据库、数据仓库、API 等，为企业的数据分析工作提供智能化的支持。

import csv
import json
import io

class DataAnalysisTools:
    """数据分析工具集"""
    
    MOCK_DATA = """
日期,产品,地区,销售额,成本,利润
2026-01-05,A,华北,15000,9000,6000
2026-01-12,B,华东,22000,13200,8800
...
"""

    @staticmethod
    def query_data(dataset, filters=None):
        """查询数据集，支持条件过滤"""
        reader = csv.DictReader(
            io.StringIO(MOCK_DATA.strip())
        )
        rows = list(reader)
        
        if filters:
            rows = [
                row for row in rows
                if all(row.get(k) == str(v) 
                       for k, v in filters.items())
            ]
        
        return json.dumps(rows, ensure_ascii=False)

2.2 指标计算与分组聚合

Python（计算与聚合工具）
    @staticmethod
    def calculate_metrics(data_json, metric):
        """计算统计指标"""
        data = json.loads(data_json)
        values = [float(row.get(metric, 0)) for row in data]
        
        return json.dumps({
            "count": len(values),
            "sum": sum(values),
            "avg": sum(values) / len(values),
            "max": max(values),
            "min": min(values)
        }, ensure_ascii=False)

    @staticmethod
    def group_by(data_json, group_key, agg_key, agg_func):
        """分组聚合"""
        data = json.loads(data_json)
        groups = {}
        
        for row in data:
            key = row.get(group_key)
            groups.setdefault(key, []).append(
                float(row.get(agg_key, 0))
            )
        
        result = {}
        for key, values in groups.items():
            if agg_func == "sum":
                result[key] = sum(values)
            elif agg_func == "avg":
                result[key] = sum(values) / len(values)
        
        return json.dumps(result, ensure_ascii=False)

三、ReAct 循环集成

数据分析 Agent 使用 ReAct 循环作为核心执行引擎。Agent 在每一步都先思考下一步应该做什么，然后选择合适的工具执行，最后观察执行结果并决定下一步行动。这种循环模式使得 Agent 能够灵活应对不同的分析需求，而不需要为每种场景编写专门的代码。

Agent 的提示词设计至关重要。它需要清晰地描述可用工具的功能和参数格式，规定输出格式要求，并提供足够的上下文信息。在数据分析场景中，提示词还需要引导 Agent 按照合理的数据分析流程进行操作：先查询数据，再计算指标，最后生成报告。

四、异常处理集成

在实际的数据分析过程中，各种异常情况都可能发生：数据查询失败（数据源不可用）、计算错误（数据格式异常）、工具超时（网络延迟）等。数据分析 Agent 集成了前面学习的异常处理机制，确保在面对各种异常时都能做出恰当的响应。

Agent 的异常处理策略是：对于临时性错误（如网络抖动），使用指数退避重试；对于数据格式错误，尝试使用默认值或回退逻辑；对于工具不可用，记录错误信息并跳过该步骤。这种分层次的异常处理策略确保了 Agent 的鲁棒性。

4.1 异常处理集成

Python（异常处理集成）
class DataAnalysisExceptionHandler:
    """数据分析异常处理器"""
    
    def __init__(self, max_retries=2, retry_delay=0.5):
        self.max_retries = max_retries
        self.retry_delay = retry_delay

    def handle(self, func, *args, **kwargs):
        """执行带异常处理的函数"""
        last_error = None
        for attempt in range(self.max_retries + 1):
            try:
                return func(*args, **kwargs)
            except Exception as e:
                last_error = e
                if attempt < self.max_retries:
                    delay = self.retry_delay * (2 ** attempt)
                    time.sleep(delay)
        
        return {"error": str(last_error)}

五、可观测性集成

数据分析 Agent 集成了完整的可观测性系统，包括执行追踪和指标收集。追踪器记录每个步骤的开始时间、结束时间、执行状态和元数据，形成完整的执行时间线。指标收集器统计总请求数、成功率、平均延迟等关键性能指标。

可观测性数据的价值不仅在于问题排查，更在于持续优化。通过分析执行追踪数据，可以发现哪些步骤耗时最长、哪些工具调用最频繁、哪些错误类型最常见。这些信息为 Agent 的性能优化提供了数据支持。

            span = self.span_stack.pop()
            span.end_time = time.time()
            span.duration = span.end_time - span.start_time
            span.status = status
            if not self.span_stack:
                self.traces.append(span)

class DataAnalysisAgent:
    """数据分析 Agent — 完整实现"""
    
    TOOLS = {
        "query_data": DataAnalysisTools.query_data,
        "calculate_metrics": DataAnalysisTools.calculate_metrics,
        "group_by": DataAnalysisTools.group_by,
        "generate_report": DataAnalysisTools.generate_report

    def __init__(self):
        self.tracer = DataAnalysisTracer()

        self.metrics = {"total_steps": 0, "success": 0}

        self.tracer.start_trace(task)
        
        # 2. ReAct 循环
        for step in range(8):

                self.execute_tool,

            )

        return {
            "success": False,
            "trace": self.tracer.export_summary(),
