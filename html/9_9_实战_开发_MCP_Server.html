二、数据库模块

数据库模块提供安全的只读数据库查询能力。模块使用 SQLite 作为示例数据库，实现了表列表查询和 SQL 查询功能。为了保证安全性，模块只允许 SELECT 查询，禁止所有修改数据库的操作。同时，查询结果会经过脱敏处理，确保敏感信息不会泄露。

数据库模块的实现分为三个步骤：首先初始化数据库并创建示例表，然后提供表列表查询功能，最后实现安全的 SQL 查询功能。每个步骤都包含了完善的安全检查和错误处理。

2.2 安全查询实现

Python（安全 SQL 查询）
import re

class InputValidator:
    """输入验证器"""
    SQL_KEYWORDS = {"DROP", "DELETE", "ALTER", "TRUNCATE", "EXEC"}
    
    @staticmethod
    def validate_sql_safe(query: str) -> bool:
        """验证 SQL 查询是否安全（只允许 SELECT）"""
        upper = query.upper().strip()
        if not upper.startswith("SELECT"):
            return False
        # 检查是否包含危险关键字
        for kw in InputValidator.SQL_KEYWORDS:
            if kw in upper:
                return False
        return True

class DatabaseTool:
    def execute_query(self, query: str, params=()) -> dict:
        """执行安全的只读查询"""
        # 1. 安全验证
        if not InputValidator.validate_sql_safe(query):
            return {"error": "只允许 SELECT 查询"}
        
        # 2. 执行查询
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        cursor = conn.cursor()
        cursor.execute(query, params)
        rows = [dict(row) for row in cursor.fetchall()]
        columns = [desc[0] for desc in cursor.description]
        conn.close()
        
        # 3. 结果脱敏
        for row in rows:
            for key, value in row.items():
                if isinstance(value, str):
                    row[key] = DataProtector.mask_sensitive(value)
        
        return {"success": True, "columns": columns, "rows": rows}

三、文件操作模块

文件操作模块提供安全的文件读写能力。模块通过路径验证防止路径遍历攻击，通过文件类型白名单限制可操作的文件类型，通过文件大小限制防止资源耗尽。这些安全措施确保了文件操作的安全性和可控性。

文件模块的核心功能包括：列出目录中的文件、读取文件内容、写入文件内容。每个功能都包含了完善的安全检查，确保不会访问受限目录或操作危险文件类型。

3.1 文件读取实现

Python（安全文件读取）
import os

class FileTool:
    """文件操作 MCP 工具"""
    
    ALLOWED_EXTENSIONS = {'.txt', '.md', '.json', '.csv', '.yaml', '.py'}
    MAX_FILE_SIZE = 1024 * 1024  # 1MB
    
    def __init__(self, base_dir="./workspace"):
        self.base_dir = os.path.abspath(base_dir)
        os.makedirs(self.base_dir, exist_ok=True)
    
    def read_file(self, file_path: str) -> dict:
        """安全读取文件"""
        # 1. 路径安全验证
        if ".." in file_path or file_path.startswith("/"):
            return {"error": "无效路径"}
        
        # 2. 扩展名白名单
        _, ext = os.path.splitext(file_path)
        if ext.lower() not in self.ALLOWED_EXTENSIONS:
            return {"error": f"不支持的文件类型: {ext}"}
        
        # 3. 文件大小检查
        full_path = os.path.join(self.base_dir, file_path)
        if os.path.getsize(full_path) > self.MAX_FILE_SIZE:
            return {"error": "文件过大"}
        
        # 4. 读取文件
        with open(full_path, 'r', encoding='utf-8') as f:
            content = f.read()
        return {"success": True, "content": content}

Web 搜索模块提供关键词搜索功能。在实际项目中，这个模块可以对接搜索引擎 API（如 Google Search API、Bing Search API 等）。为了演示目的，本模块使用本地索引模拟搜索功能，展示了搜索的基本流程和结果处理。

搜索模块包含关键词匹配、相关性排序、结果限制等功能。模块还实现了搜索频率限制，防止 API 被滥用。在实际部署时，可以将本地索引替换为真实的搜索引擎 API 调用。

4.1 搜索实现

Python（关键词搜索）
class WebSearchTool:
    """Web 搜索 MCP 工具"""
    
    def __init__(self):
        self.index = [
            {"title": "MCP 协议官方文档", "url": "https://mcp.dev",
             "summary": "Model Context Protocol 官方文档..."},
            {"title": "Function Calling 指南", "url": "https://docs.ai/fc",
             "summary": "Function Calling 完整指南..."},
        ]
        self.search_count = 0
        self.max_searches = 50
    
    def search(self, query: str, limit: int = 5) -> dict:
        """执行搜索"""
        if not query or len(query.strip()) < 2:
            return {"error": "搜索关键词至少 2 个字符"}
        
        self.search_count += 1
        if self.search_count > self.max_searches:
            return {"error": "搜索频率超限"}
        
        # 关键词匹配
        query_lower = query.lower()
        results = []
        for item in self.index:
            if query_lower in item["title"].lower():
                results.append(item)
        
        return {"success": True, "results": results[:limit], "total": len(results)}

五、综合服务器

综合服务器将数据库、文件和搜索三大模块集成在一起，提供统一的工具调用接口。服务器通过工具名称路由到对应的模块，执行相应的操作并返回结果。同时，服务器维护审计日志，记录所有工具调用的详细信息。

5.1 服务器实现

Python（综合 MCP Server）
class PracticalMCPServer:
    """实战 MCP Server"""
    
    def __init__(self, workspace_dir="./workspace"):
        self.db = DatabaseTool()
        self.files = FileTool(workspace_dir)
        self.search = WebSearchTool()
        self.audit_log = []
    
    def handle_tool_call(self, tool_name, arguments):
        """路由工具调用"""
        try:
            if tool_name == "db_list_tables":
                return self.db.list_tables()
            elif tool_name == "db_query":
                return self.db.execute_query(arguments.get("sql", ""))
            elif tool_name == "file_read":
                return self.files.read_file(arguments.get("path", ""))
            elif tool_name == "file_write":
                return self.files.write_file(
                    arguments.get("path", ""),
                    arguments.get("content", "")
                )
            elif tool_name == "web_search":
                return self.search.search(arguments.get("query", ""))
            return {"error": f"未知工具: {tool_name}"}
        except Exception as e:
            return {"error": str(e)}
